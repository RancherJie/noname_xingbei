### 角色组专用AI（2026-10-18）

本轮按每名角色的资源循环、费用牌和额外行动定制AI。目标是有合法机会且收益适合当前局面时积极发动，不能承诺无条件发动率；强制技能、资源标记与没有合法机会的分支不纳入主动发动率。真人发动条件、技能费用与结算规则不变，AI判断统一通过注册技能中的辅助方法调用，避免联机选择回调依赖宿主闭包。

## 世界观与背景故事（2026-10-18确认）

### 系列定位与叙事基调

《百年战争》共四部，当前扩展承担首部《初》的故事，现有扩展目录与注册名沿用“百年战争·序章”。第一部让玩家认识星界、五个阵营与十五名角色，逐步发现百年战争和诅咒之间的联系；星之门关闭的真相、原初五星杯的完整作用及最终结局留给后续三部展开。

故事的核心是：**战争已经持续了一百年，她们却拥有十二至十六岁少女的身体。星界失去了成长，却仍在消耗时间。**

画面与日常可以明亮、温暖，人物关系承载战争留下的伤痕。女孩们有各自的愿望、习惯、牵挂与矛盾；外表年龄、实际经历和心理状态需要分别理解。宏大的阵营目标落到保护朋友、维持住处、完成承诺等具体选择上，日常生活与冒险应贯穿四部作品。

### 星界、星石与星杯

故事发生在**星界**。这里的天空常年可见星河，群山、海洋与城市之间散布着星石矿脉。星石凝聚来自群星的力量，既用于法术，也用于晶械、航船、照明和城市结界。小块水晶维持普通人家的灯火，繁荣都市则依赖持续的星石供应。

沿用《星杯传说》的基础规则关系：星石分为**宝石**与**水晶**；星石经过提炼成为角色可使用的能量，三个星石可以合成一个星杯。这些关系取自[《星杯传说》规则说明书](https://m102.nthu.edu.tw/~s102061202/Asteriated%20Grail%20v17.8.9.pdf)。

本系列将星杯分为两个叙事层次：

- **日常合成的星杯**：由星石凝聚而成的稳定能量核心，能够支持大型法术、结界与仪式，是维持城市和战争的战略资源。
- **原初五星杯**：维系星界与另一世界联系的古老圣物，与星之门、生命循环及世界形态有关。恢复它们之间的联系，才有可能触及停龄诅咒。

公开背景整理中“五个星杯维系两个世界平衡、星之门关闭后生命循环停滞”的线索，作为本系列改编的起点，参见[《星杯传说》背景资料整理](https://www.pttweb.cc/bbs/BoardGame/M.1441970567.A.4C8)。星界地理、停龄诅咒、两层星杯的具体区分和下述剧情属于本系列原创改编，不作为原作官方背景引文；普通合成星杯不能直接等同于原初五星杯。

### 返龄之日与停龄诅咒

百年前，**星之门关闭了**。同一天，星界所有智慧种族的居民，都变成了十二至十六岁少女的形态。人们将这一天称为**返龄之日**，将持续至今的异常称为**停龄诅咒**。

- 居民保留原有记忆、知识、技艺与身份，也保留精灵尖耳、角等种族特征；身体、声音与力量的使用方式受到改变。
- 身体此后停止成长。疾病、受伤、死亡、饥饿和资源消耗仍然存在，停龄不代表不死。
- 外表年龄不自动等于实际年龄或心理年龄。每名角色的实际年龄、诅咒前身份及记忆完整程度，需要后续逐名确定，不能仅凭称号推定。
- 诅咒后新生命的诞生方式、成长过程和完整寿命规则尚未确定，后续设定需要与“全体少女形态、身体停止成长”的前提一致。

故事前期流传一种解释：**原初星杯正在以第一位守杯少女的形态，修补失去循环的生命。**教廷中有人将其理解为庇护，学者中有人认为这是世界发生的错误。这是星界居民的解释，其真实性与完整程度保留为后续悬念。

人们照常庆祝生日，旧时代的衣甲、王座与成人画像也仍然留存。“长大”逐渐成为只能从旧记录中理解的经历。停龄者对恢复旧世界的执着，与只熟悉当下生活者对改变的担忧，可以形成跨阵营的人物冲突。

### 首部《初》的故事主线

暮星镇依靠一座古老星杯设施维持结界，并为来往旅人提炼星石。五方都需要这条交通线，因此即使战争持续，镇子仍保留着脆弱的中立地位。十五名角色因护送、调查、修学或寻找失踪者等不同任务来到这里；具体任务归属留待逐名编写。

前段通过集市、临时住处、训练与节庆建立人物关系，让角色首先作为生活在星界的人被认识。

事件由一次合成仪式的异常开始：星石没有凝成预期的星杯，反而映出一名陌生少女的身影。随后，一名居民出现百年来首次被可靠记录的**成长**迹象。异常者的身份、陌生少女与守杯者的关系暂不揭晓。

消息牵动五方：战技殿堂要保护现场，教廷要求接管异常者，咏歌城希望检查设施，幻影联盟试图带走相关记录，鲜血议会怀疑异常者的身体正在承担无法承受的变化。女孩们最初各自相信，自己是在阻止别人把事情弄坏；不同命令与逐渐建立的信任使她们陷入冲突。

第一部结尾，她们共同保住暮星镇，并在设施深处发现一道来自寂门的讯息：

> 星界历第一百年，守杯者仍未归位。

结尾留下线索：星石消耗、星杯合成、停龄诅咒与持续百年的战争，可能都在推动同一个尚未完成的仪式。该关联在第一部作为疑问呈现，不能提前写成角色已经掌握的完整真相。
